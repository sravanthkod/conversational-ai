## If Something Breaks

- Replit limits background services
- Fallback: Use mock LLM instead
- Edit app.py: Comment out OllamaProvider
- It'll still work (with mock responses)

**"Model not found" error**
- Download mistral: `ollama pull mistral`
- Or use smaller: `ollama pull neural-chat`

**Replit times out**
- Replit free tier has limits
- Use your local http://localhost:5000 for demo
