# Quick Start - Run the Real System (10 minutes)

This gets you from zero to **actually intelligent AI** with real LLM responses.

---

## The Setup

You need **3 things running simultaneously**:
1. **Ollama** (LLM engine)
2. **Flask app** (web server)
3. **Browser** (to chat)

---

## Start Here

### **Terminal 1: Start Ollama**
```bash
# First time only - download the model (takes 5-10 min)
ollama pull mistral

# Then start the server (leave this running)
ollama serve
```

You should see:
```
time=2024-01-15T10:00:00Z level=INFO msg="Listening on 127.0.0.1:11434"
```

✅ **Ollama is ready**

---

### **Terminal 2: Start Your App**
```bash
cd ConversationalAI_Prototype
pip install -r requirements.txt
python app.py
```

You should see:
```
✓ Connected to Ollama (mistral)
 * Running on http://127.0.0.1:5000
 * Press CTRL+C to quit
```

✅ **App is ready**

---

### **Step 3: Open in Browser**
Go to: **http://localhost:5000**

You should see the beautiful chat interface.

✅ **You're live!**

## Making It Even Better

### **Faster Responses** (if slow)
```bash
ollama pull neural-chat
```

Then in `app.py`, change:
```python
ollama = OllamaProvider(model="neural-chat")
```

### **Better Quality** (if responses feel generic)
```bash
ollama pull llama2
```

Then in `app.py`, change:
```python
ollama = OllamaProvider(model="llama2")
```

### **More Creative Responses**
In `app.py`, change:
```python
response = self.llm_provider.generate(prompt, temperature=0.9)  # was 0.7
```

## Troubleshooting

**Q: "Connection refused"**
```
✗ Ollama isn't running. Start it with: ollama serve
```

**Q: "Model not found"**
```
✗ Download it: ollama pull mistral
```

**Q: Responses are slow**
```
✓ Normal on first run (LLM needs to load)
✓ Try smaller model: ollama pull neural-chat
```

**Q: "Out of memory"**
```
✓ Close other apps
✓ Use smaller model: neural-chat or mistral (not llama2)
```

**Q: Port 5000 already in use**
```
Change in app.py:
app.run(port=5001)  # Use different port
```
